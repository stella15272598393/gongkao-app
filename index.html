    ⚙️ 数据备份

    所有学习记录都存在本机，换手机或清缓存前记得备份～

    📤 导出全部学习数据
    收藏、成语错词、打卡、待办、速算错题等，导出为一个 JSON 文件
    📥 导入学习数据
    选择之前导出的 JSON 恢复（覆盖同名记录）
    ☁️ 跨设备云同步（GitHub Gist）
    把学习数据备份到私有 Gist，换手机或清缓存后一键恢复。Token 仅存本机，不会上传到任何服务器。
    ① GitHub → Settings → Developer settings → Personal access tokens，生成 token（勾选 gist）
    ② 点「备份到云端」会创建私有 Gist 并自动回填 Gist ID
    ③ 另一台设备填相同 Gist ID + 各自 token，点「从云端恢复」
